PhiTeX logo: the woven ribbon

ΦTeX in CMU Serif Bold. TeX is set exactly as TeX sets it (T\kern-.1667em\lower.5ex\hbox{E}\kern-.125emX), and the Φ is lowered by the same .5ex. The stripes are ACCL's (8, 6.17, 4.33 and 2.5, gaps of 2.5, slant 54°), scaled so the orange is half the T's stem. Where a stripe and a letter cross, the one underneath leaves ACCL's 2.5 gap. Everything is generated from WORD, STRIPE and STYLES below; each style says, for every letter, what lies on top.
