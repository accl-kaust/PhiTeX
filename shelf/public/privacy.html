Privacy policy

PhiTeX Instant for Overleaf (unofficial), a Chrome extension. Not made, endorsed or supported by Overleaf.

Effective 2 October 2026.

Summary

The extension collects no personal data. Your documents never leave your browser. There are no analytics, accounts, ads or tracking.

What the extension reads

On Overleaf project pages (https://www.overleaf.com/project/…) it reads the project you are editing (its files and the editor's text) to typeset a preview. This happens entirely in your browser, in WebAssembly. Your documents are kept in memory only while the tab is open, and are never sent to us or anyone else.

Network requests

  • overleaf.com: your own project's files, fetched as you, the same way Overleaf's editor fetches them. The extension never writes to Overleaf.
  • Shelf (shelf-phitex.pages.dev, static files on Cloudflare Pages): when a document uses a TeX package the extension doesn't bundle, it downloads that package's file, e.g. tikz.sty, and a list of the package names available. Only names in that list are requested, never your own file names, and no document text or identifier is sent. Each file is downloaded once and then kept in your browser. As with any website, Cloudflare receives your IP address and the requested file name. Shelf keeps no logs of its own. See Cloudflare's privacy policy.

What is stored

In your browser only: your settings (preview on or off, zoom, layout, output format), whether you accepted the first-run notice, and downloaded TeX package files. Nothing is stored on any server. Removing the extension deletes all of it.

Sharing

No user data is collected, so none is sold, shared or transferred, or used for anything other than showing the preview.

Changes and contact

Changes to this policy will be posted on this page. Questions: open an issue at the extension's source repository.
