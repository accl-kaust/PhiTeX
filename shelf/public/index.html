Shelf

TeX Live's LaTeX packages, one file per URL, for PhiTeX's in-browser builds.

GET /tl2026/<name> — a file as TeX would find it by name (/tl2026/graphicx.sty).
GET /tl2026/names.txt — every name served, one per line.

Files are TeX Live 2026's, unmodified, each under its own license (mostly the LaTeX Project Public License); see each file's header. No logs of who asks for what are kept beyond the host's defaults.
